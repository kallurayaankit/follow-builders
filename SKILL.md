# Follow Builders, Not Influencers  This is your custom AI digest tool.  It fetches AI blog posts and prepares a summary.  ## Usage  1. Run `node scripts/generate-feed.js` to create `feed-blogs.json`.  2. Run `node scripts/prepare-digest.js` to output a JSON payload with feed data and prompts.  3. Pipe the output to an LLM or use `node scripts/deliver.js` to send to Telegram.  No API keys needed for content fetching.  All configuration lives in `~/.follow-builders/config.json`.
